JBossWS-CXF 7.4.0.Final has been released. In this release we upgraded Apache CXF to 4.1.6, aligned Jakarta and 
JBoss dependencies to WildFly, and moved to jboss-jakarta-xml-ws-api 4.0 spec.

See more details in [the last Blog post]({% post_url 2026-05-28-jbossws-740-release %})

Please try out this release, and let us know if you have any issues or questions.
